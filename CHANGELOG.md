# Changelog

## 1.1.0 — 2026-10

First public release on GitHub.

- 22 effects: mesh-gradient, aurora, lightfall, particles, wave-lines, dot-grid, globe, grain, spotlight, border-beam, tilt, ripple-image, image-trail, parallax, split-reveal, text-scramble, typewriter, gooey-text, number-ticker, marquee, cursor, magnetic.
- Full bundle (`dist/dopamine-fx.min.js`) and one file per effect (`dist/effects/`).
- `window.DopamineFX.<effect>()` re-scans the page for elements added after load.
